# Sales & Pricing Database

## Project Overview

This project is a MySQL-based Sales & Pricing Database designed to demonstrate core SQL concepts used in business reporting and data analysis.

The database tracks customers, products, orders, and order items, allowing users to generate sales reports, analyze customer purchases, identify top-selling products, and apply pricing logic using SQL queries.

## Database Schema

The project consists of four tables:

### Customers

Stores customer information including customer type and city.

### Products

Stores product details, categories, and prices.

### Orders

Stores customer orders and order dates.

### Order Items

Stores products purchased in each order along with quantities.

## Reports Generated

### 1. Order Details Report

Displays customer orders, products purchased, quantities, prices, and total amounts.

### 2. Total Sales by Customer

Calculates total sales generated by each customer.

### 3. Top Selling Products

Identifies products with the highest quantity sold.

### 4. Revenue by Category

Calculates revenue generated by each product category.

### 5. Premium Customer Sales

Analyzes sales generated by premium customers.

### 6. High Value Orders

Identifies orders with values above a specified threshold.

### 7. Pricing Logic & Discount

Applies discount categories using SQL CASE statements based on customer spending.
